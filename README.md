# Hi, I'm Sriram Balasubramanian

I'm a quantity surveyor from Singapore, learning to build software. I'm applying to university to study engineering, and this profile is my portfolio: small, working tools I built from problems I ran into at work.

## How I build

Every project here starts the same way. I hit a problem on site or in a spreadsheet, something slow, fiddly or easy to get wrong, and I build a tool that does it properly. Then I test it, write down how to run it, and say plainly what it can and cannot do. No fake clients, no pretend products. The sample data is made up, the code is real.

## What I'm building

### Cost and pricing

Tools from my quantity surveying work, the part of construction where a wrong number costs real money.

- [CostTrack API](https://github.com/sriram2932/costtrack-api): a working FastAPI service for BOQ items and cost estimates, with auth and rate limiting
- [CostTrack API docs](https://github.com/sriram2932/costtrack-api-docs): developer documentation sample, API reference, CLI help and a how-to guide
- [boq-rate-predictor](https://github.com/sriram2932/boq-rate-predictor): predicts BOQ item rates from past priced items, using a small machine learning model I wrote from scratch in plain Python
- [tender-compare](https://github.com/sriram2932/tender-compare): a web app that compares priced BOQs across bidders in seconds, ranks them, and flags the rates that sit far from the median

### Planning and project control

- [cpm-scheduler](https://github.com/sriram2932/cpm-scheduler): critical path scheduling from a task list, with a text Gantt chart
- [earned-value-tracker](https://github.com/sriram2932/earned-value-tracker): earned value metrics (CPI, SPI, EAC) from one CSV, so you can see in a minute whether a project is over budget, behind schedule, or both
